# ToDOCX

琐碎排版，一键告别。

ToDOCX 是一个面向 Windows 的桌面排版工具，用来将现有文档整理为结构更统一、格式更规范的 `.docx` 文件。  
它目前聚焦 3 类输入：

- `DOCX`：对已有 Word 文档进行智能再排版
- `LaTeX (.tex)`：转换为结构化的 Word 文档
- `Markdown (.md / .markdown)`：转换为样式统一的 Word 文档

项目使用 `PyQt5` 构建桌面界面，支持样式模板、段落类型调整、输出目录控制，以及本地优先的安全策略。

> 当前版本：`v1.0.4`

## 项目定位

ToDOCX 不是一个“万能格式转换器”，而是一个专注于“排版整理”的桌面工具。

它适合以下场景：

- 已经有一份 Word 文档，但格式混乱，希望快速统一标题、正文、代码、图表标题等样式
- 有一份 LaTeX 或 Markdown 内容，希望输出成更适合提交、打印、存档的 `.docx`
- 需要在多次使用中复用同一套样式模板

它不追求覆盖所有文档格式，也不依赖云端服务。默认工作方式是本地处理、本地存储、本地输出。

## 核心能力

### 1. DOCX 智能再排版

- 读取现有 Word 文档并分析段落结构
- 自动识别标题、正文、代码、引用、图表标题等类型
- 在右侧预览区查看识别结果，并通过右键手动调整段落类型
- 按当前样式设置重新生成新的 `.docx`
- 支持编号列表段落字体同步调整，包括编号本身

### 2. LaTeX 转 DOCX

- 识别章节结构并输出带层级感的 Word 标题
- 解析常见表格环境并生成真实 Word 表格
- 识别 `lstlisting`、`verbatim` 等代码环境并保留为代码块
- 将块级公式输出为 Word 公式对象（OMML）
- 处理常见 LaTeX 转义与 `\url{}`、`\href{}` 等链接文本

### 3. Markdown 转 DOCX

- 支持标题、代码块、引用、表格、公式等常见 Markdown 结构
- 允许在预览区按识别类型进行调整
- 复用与 DOCX / LaTeX 相同的样式体系输出到 `.docx`

### 4. 样式模板

- 内置默认模板
- 支持将当前样式保存为用户模板
- 支持加载、重命名、删除用户模板
- 用户模板会持久化到用户目录，便于升级和多次复用

### 5. 可控输出

- 默认输出到源文件所在目录
- 支持自定义输出目录
- UI 中提供取消功能，避免长时间转换时界面像“卡住”

## 当前安全与行为约束

为了保证桌面工具在打开第三方文档时更稳妥，当前版本采用了更严格的本地策略：

- Markdown 中的远程图片链接不会被下载
- Markdown 中的本地图片只能引用当前文档目录及其子目录内的相对路径
- `../` 越界路径和绝对路径会被阻止
- 模板、设置、日志都存放在用户目录，而不是源码目录
- 模板保存采用原子写入，并带结构校验

这意味着：

- 如果 Markdown 里写的是 `![img](https://example.com/a.png)`，转换时不会联网抓图
- 如果图片引用超出了当前 Markdown 所在目录，图片会被阻止而不是静默读取

## 快速开始

### 方式一：直接使用已发布版本

适合普通用户。

1. 前往 GitHub Release 页面下载最新发布包  
   当前发布版本：`v1.0.4`
2. 解压 `ToDOCX-v1.0.4-win64.zip`
3. 进入解压后的 `ToDOCX` 目录
4. 运行其中的 `ToDOCX.exe`

> 从 `v1.0.4` 开始，发布包采用 `onedir` 方式分发。  
> 相比单文件 exe，体积更小，启动也更快。

### 方式二：开发环境运行

适合需要调试或修改代码的开发者。

#### 环境要求

- Windows
- Python `3.10+`
- 建议使用项目内虚拟环境 `.venv`

#### 安装依赖

```powershell
uv sync
```

#### 启动程序

```powershell
.\.venv\Scripts\python.exe .\main.py
```

## 使用流程

1. 启动应用后，在左侧拖入或选择一个输入文件
2. 支持的输入文件类型：
   - `.docx`
   - `.tex`
   - `.md`
   - `.markdown`
3. 在左侧“样式”页中设置标题、正文、图表标题、代码等样式
4. 如有需要，在“模板”页保存或加载模板
5. 在右侧预览区查看自动识别结果，并可右键调整类型
6. 设置输出目录，或留空使用源文件所在目录
7. 点击“开始转换”
8. 如任务较长，可点击“取消”

## 用户数据目录

程序运行时会在用户目录下保存设置、模板和日志。

默认位置：

```text
%APPDATA%\ToDOCX
```

主要内容包括：

- `settings.json`：用户设置
- `templates\`：用户模板
- `logs\todocx.log`：日志文件

这套结构更适合升级、重装和多次使用，也避免把用户数据写进安装目录。
